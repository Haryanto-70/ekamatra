# Proyek Kubika — Website PT Kubika Karya Indonesia

Website company profile untuk **PT Kubika Karya Indonesia**, kontraktor Design & Build Residential yang didukung keahlian Mekanikal, Elektrikal & Plumbing (MEP).

## Lokasi Repository

- **GitHub**: [Haryanto-70/ekamatra](https://github.com/Haryanto-70/ekamatra)
- **Branch**: `claude/kubika-website-build-rh5obr`
- **Folder proyek**: [`proyek-kubika/`](https://github.com/Haryanto-70/ekamatra/tree/claude/kubika-website-build-rh5obr/proyek-kubika)

## Struktur

```
proyek-kubika/
├── index.html        # Halaman utama (one-page site)
├── css/style.css      # Styling
├── js/script.js       # Interaksi (nav, header on scroll)
└── assets/img/        # Foto proyek & logo (diambil dari Company Profile PT Kubika Karya Indonesia)
```

## Konten

Seluruh isi (tentang, visi & misi, proyek, layanan MEP, kenapa memilih Kubika, kontak) diambil dari materi *Company Profile PT Kubika Karya Indonesia — MEP*.

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan static server sederhana:

```bash
cd proyek-kubika
python3 -m http.server 8000
```

Lalu akses `http://localhost:8000`.
